# 123FastLink 修复版

基于上游 [Bao-qing/123FastLink](https://github.com/Bao-qing/123FastLink)（`v2026.9.2.1`）修改，当前修复版为 **v2026.10.1.1**。

修复内容：大 JSON 清单分块导入、失败详情与重试。

## 安装方法

1. 浏览器先安装 Tampermonkey。
2. 安装：
   - [123 网盘版](https://raw.githubusercontent.com/sunuuc/123FastLink/main/dist/123FastLink.v3.user.js)
3. 打开链接，在 Tampermonkey 页面点击“安装”。
4. 打开 123 网盘并刷新，确认脚本版本为 **2026.10.1.1**。

更新时重新打开对应的本分支链接并安装新版。
